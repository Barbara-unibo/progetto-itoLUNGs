# Canine Lung Histology: ImageNet vs. Human-Lung Pre-training (ConvNeXt-Tiny)

Binary classification (**Normal vs. Neoplastic**) of canine lung H&E images. The project compares two
transfer-learning strategies on **identical patient-level folds**:

| Setting | Initialisation of ConvNeXt-Tiny | Fine-tuning |
|---|---|---|
| **A** | ImageNet-1k | canine dataset |
| **B** | ImageNet-1k → pre-trained on **LungHist700** (human lung) | canine dataset |

Human and canine images are **never mixed** in one training set. LungHist700 is used only for
pre-training (step 1), the canine data only for fine-tuning and evaluation (step 2).

---

## 1. Experimental design

```
            ImageNet ConvNeXt-Tiny
              │                 │
              │        pre-train on LungHist700 (binary, human only)
              │                 │
      A) fine-tune         B) fine-tune          ← same folds, same inner-val patients,
         on canine            on canine             same seed, same hyper-parameters
              │                 │
        test fold k        test fold k          ← evaluated once with the best checkpoint
              └──── Grad-CAM side by side ────┘
```

* **Patient-level 5-fold CV stratified by Normal/Neoplastic** (`StratifiedGroupKFold`, groups =
  `case_id`, y = `label`). Every patient's images stay in one fold, and the Normal/Neoplastic
  proportion is balanced across folds. Tumour subtype is not used. The fold assignment is saved to `results/folds.csv` and reused by every run,
  so A and B are evaluated on exactly the same patients.
* **No model selection on the test fold.** In each fold, ~20 % of the *training* patients are held
  out as an inner validation set. The checkpoint with the highest validation **balanced accuracy**
  is kept (ties → lower validation loss) and evaluated once on the test patients.
* **Controlled comparison.** For a given fold, A and B use the same seed, so they get the same head
  initialisation, batch order and augmentations. Only the backbone initialisation differs. By default
  B re-initialises the classification head (`--keep-pretrained-head` keeps the LungHist700 head).
* **Pre-training is done once** (independent of the canine folds, so it cannot leak canine test
  data). A patient-level 80/20 split of LungHist700 selects the best pre-training epoch.

### Training recipe (both phases)

| | |
|---|---|
| Model | torchvision `convnext_tiny`, `IMAGENET1K_V1`, new 2-class linear head |
| Input | 512 × 512, ImageNet normalisation |
| Augmentation (train) | RandomResizedCrop (scale 0.5–1), H/V flips, 90° rotations, mild colour jitter (H&E stain variability) |
| Evaluation | whole field of view resized to 512 × 512 |
| Optimiser | AdamW (lr 1e-4, weight decay 0.05; no decay on norms/biases/layer-scale) |
| Schedule | CosineAnnealingLR to 1e-6 over 30 epochs |
| Loss | Cross-entropy, label smoothing 0.1, inverse-frequency class weights |
| Precision | AMP float16 + GradScaler (or `--amp-dtype bfloat16`), channels-last, TF32 |
| Stability | gradient clipping (max-norm 1.0), non-finite loss check |

## 4. Data

### 4.1 Canine dataset (private)

The training code expects a CSV with at least:

| column | meaning |
|---|---|
| `case_id` | patient / lung identifier (used for grouping, never split across folds) |
| `image_path` | absolute, or relative to the CSV's folder |
| `label` | `0` = Normal, `1` = Neoplastic |

Optional columns `subtype` and `magnification` are informational only. They are kept and copied into
the prediction files.

Build it from the raw spreadsheet (`PATIENT_ID, IMAGE_ID, OBJECTIVE, SUPERCLASS`) and the image folders:

```powershell
python train.py prepare
# or explicitly:
python train.py prepare --raw-csv "data/CANINELUNGHISTO(Foglio1).csv" --image-dirs data/nn data/neo --canine-csv data/canine.csv
```

The spreadsheet only supplies the **image ID → patient** mapping. The label comes from the file
name (`nn_*` → Normal, any other prefix → Neoplastic). Every inconsistency is logged in
`results/logs/prepare_*.log`. Files that cannot be assigned to a patient are **excluded**, never guessed.

> **Data-quality issues found in the current spreadsheet** (please fix them at the source if possible):
> * `nn_66_40x … nn_69_40x`: the spreadsheet repeats `IMAGE_ID 65` four times instead of 66–69, so these 4 files have no patient. They are excluded.
> * `nn_348_40x`, `nn_982_20x`: IDs absent from the spreadsheet → excluded (IDs 248, 629, 882 are listed twice).
>
> After `prepare`, check the log for the final counts (expected ≈ 992 images, 50 cases).

### 4.2 LungHist700 (human, pre-training only)

Diosdado *et al.*, *LungHist700: A dataset of histological images for deep learning in pulmonary
pathology*, Scientific Data 11, 1088 (2024). Download it from the figshare link in the paper and
extract it to `data/LungHist700/`.

Binary mapping: `nor` → Normal (0); `aca_*` (adenocarcinoma) and `scc_*` (squamous cell carcinoma),
all differentiation grades → Neoplastic (1). Both 20× and 40× images are used.

Auto-indexing scans every image under `--lunghist-root`. It takes the class from file-name tokens or
folder names, and the **patient ID** from the metadata CSV shipped with the dataset (a column containing
"patient", matched by file name or by `superclass_subclass_resolution_imageid`). The log reports how
many images were matched. If no patient IDs can be matched, a warning is logged and the pre-training
validation split falls back to image level. In that case, or for full control, provide your own index:

```powershell
python train.py pretrain --lunghist-csv data/lunghist700_index.csv   # columns: case_id,image_path,label
```

## 5. Usage

```powershell
python train.py prepare          # 1. canine CSV
python train.py pretrain         # 2. ImageNet -> LungHist700        (results/pretrain/)
python train.py cv               # 3. 5-fold CV, settings A + B, Grad-CAM, summary  (results/cv/)
# or 2+3 in one go:
python train.py all
```

Useful options (see `python train.py <command> -h`):

```powershell
python train.py cv --folds 1 2 --resume            # run/continue selected folds only
python train.py cv --settings imagenet             # setting A only (no pre-training needed)
python train.py cv --finetune-epochs 40 --batch-size 8 --num-workers 4
python train.py cv --amp-dtype bfloat16            # bf16 AMP on Ampere/Ada/Blackwell
python train.py gradcam --gradcam-per-class 6 --gradcam-target pred
python train.py summarize                          # rebuild tables from finished runs
python train.py all --deterministic                # bit-reproducible (slower)
```

Every CLI flag overrides the matching field in `src/config.py`. The resolved configuration of each
run is saved as `results/logs/config_<command>_<timestamp>.json`.

**Memory:** batch size 12 at 512² with fp16 AMP fits in ~12 GB. Reduce `--batch-size` if you get CUDA OOM.
**Windows:** if DataLoader workers cause problems, try `--num-workers 0` to debug.

## 6. Outputs

```
results/
├── logs/                               # log + resolved config of every command
├── folds.csv                           # case_id -> fold (shared by A and B, reused by every run)
├── pretrain/
│   ├── best_lunghist700.pt             # checkpoint used to initialise setting B
│   ├── split.csv, history.csv, training_curves.png
│   ├── val_predictions.csv, val_metrics.json, confusion_matrix_val.png
└── cv/
    ├── fold_<k>/
    │   ├── split.csv                   # train / inner-val / test patients of this fold
    │   ├── imagenet/                   # setting A
    │   │   ├── best_model.pt           # best epoch by inner-val balanced accuracy
    │   │   ├── history.csv, training_curves.png
    │   │   ├── test_predictions.csv    # per image: label, pred, P(neoplastic)
    │   │   ├── test_metrics.json, confusion_matrix_test.png
    │   ├── lunghist/                   # setting B (same files)
    │   └── gradcam/
    │       ├── comparison_fold<k>.png  # original | Grad-CAM A | Grad-CAM B
    │       ├── images/<image>.png      # one high-resolution panel per image
    │       └── gradcam_samples.csv
    ├── per_fold_metrics.csv
    ├── summary_metrics.csv             # mean, std per setting + paired delta (B - A)
    ├── summary.md                      # "mean ± std" table ready for the thesis
    ├── all_test_predictions.csv
    ├── confusion_matrix_<setting>_all_folds.png
    └── confusion_matrices_comparison.png
```

**Metrics** (positive class = Neoplastic): balanced accuracy, accuracy, sensitivity, specificity,
precision, F1, MCC, ROC-AUC. Reported as mean ± sample std (ddof = 1) over the 5 test folds. The
paired per-fold difference B − A is also reported. Checkpoints are about 110 MB each (about 1.2 GB
for 5 folds × 2 settings + pre-training).

**Grad-CAM** uses the last ConvNeXt stage (`features[-1]`, 16 × 16 map for 512² input) and is
computed in fp32. For every fold, the same class-balanced test images (fixed by the seed) are
explained by both models. By default the CAM targets the **ground-truth class** (`--gradcam-target pred`
uses each model's own prediction). Panel titles are green for correct and red for wrong predictions.

## 7. Reproducibility

* Global seeds (Python, NumPy, PyTorch, CUDA) plus seeded DataLoader generators and `worker_init_fn`.
  Fold *k* uses seed `seed + k` for both settings.
* Folds and inner splits are persisted (`folds.csv`, `fold_<k>/split.csv`), and a leakage check
  asserts that train, validation and test patients are disjoint.
* `--deterministic` enables deterministic cuDNN/cuBLAS algorithms. Without it, `cudnn.benchmark` is on
  and results can vary slightly between runs on GPU.

## 8. Notes and limitations for the thesis

* Normal canine images come from the same lungs as the tumours. Patient-level grouping keeps a
  lung's normal and neoplastic images in the same fold, so the model cannot exploit patient-specific
  appearance.
* With 50 patients, 5 folds give 10 test patients per fold. Fold-to-fold variance is expected to be
  large, so interpret the paired differences rather than single folds. A Wilcoxon signed-rank test on 5
  pairs cannot reach p < 0.05; consider repeating the CV with different `--seed` values (and a fresh
  `folds.csv` / `--output-dir` per repetition) if you need more statistical power.
* Images are classified individually. Patient-level diagnosis is out of scope.
